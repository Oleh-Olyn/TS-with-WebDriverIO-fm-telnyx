# TS-with-WebDriverIO-fm-telnyx

## Summary of the repository

This project contains automated end-to-end UI tests for the **Telnyx** website using **WebDriverIO, TypeScript and Mocha**.
The project uses the Page Object Model (POM) pattern to organize page elements and test actions.
The project includes:
- WebDriverIO and TypeScript
- Mocha test framework
- Page Object Model
- Chrome, Firefox and Microsoft Edge browser configurations
- Headless test execution
- Docker and Docker Compose support
- Allure test reporting
- GitHub Actions CI/CD pipeline
- Automatic Allure report deployment to GitHub Pages

The CI pipeline automatically:
- installs project dependencies
- builds the Docker image
- runs WebDriverIO tests
- generates Allure test results
- creates the Allure report
- uploads the report as a GitHub Pages artifact
- deploys the report to GitHub Pages

## Requirements

Before running the project locally, make sure you have installed:
- Node.js >= 18
- npm
- Git
- Docker
- Docker Compose

For running tests directly without Docker, the required browsers should also be installed:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
  
## Steps to install

Clone the repository:
git clone https://github.com/Oleh-Olyn/TS-with-WebDriverIO-fm-telnyx.git

Navigate to the project folder:
cd TS-with-WebDriverIO-fm-telnyx

Install project dependencies:
npm install

## Steps to launch tests
### Run all tests
npm test

### Run tests in Chrome
npm run test:chrome

### Run tests in Chrome headless mode
npm run test:chrome:headless

### Run tests in Firefox
npm run test:firefox

### Run tests in Firefox headless mode
npm run test:firefox:headless

### Run tests in Microsoft Edge
npm run test:edge

### Run tests in Microsoft Edge headless mode
npm run test:edge:headless

## Run tests with Docker
Build the Docker image:
docker compose build

Run the tests:
docker compose up --exit-code-from tests

The Docker configuration allows the tests to run in an isolated environment without requiring the browser to be installed directly on the host machine.
Allure results are saved to:
allure-results/

## Steps to create Allure report
### 1. Run tests
Run the WebDriverIO tests with Allure reporting enabled:
npm run test:chrome

The test results are generated in:
allure-results/

### 2. Generate Allure report
Generate the HTML report:
npm run allure:generate

This creates:
allure-report/

### 3. Open Allure report locally
Run:
npm run allure:open

The generated Allure report will open in the browser.

### Generate and open the report
You can also use:
npm run allure:report

## Allure Report

The Allure report is automatically generated by the GitHub Actions pipeline and deployed to GitHub Pages after successful execution.
The deployed report is available at:
https://oleh-olyn.github.io/TS-with-WebDriverIO-fm-telnyx/

## CI/CD Pipeline
The project uses **GitHub Actions** for continuous integration.
The pipeline:
1. Checks out the repository.
2. Builds the Docker image.
3. Runs WebDriverIO tests.
4. Saves Allure results.
5. Uploads Allure results as an artifact.
6. Generates the Allure HTML report.
7. Uploads the report to GitHub Pages.
8. Deploys the report to GitHub Pages.

The workflow is triggered on:
- Push to `main`
- Pull request to `main`
- Manual workflow execution
